# 🖥️ Aula 3 — Sites Estáticos e Dinâmicos

> Conceitos • Tecnologias • Aplicações • Comparações Práticas

---

## 🎯 Objetivos
- Entender o que define um site estático e um dinâmico
- Identificar quando e por que usar cada tipo
- Conhecer tecnologias utilizadas em cada abordagem
- Explorar exemplos e iniciar estruturação de um projeto simples

---

## 📖 Conceitos Fundamentais

### 🔸 Site Estático
- Conteúdo fixo, pré-renderizado
- Exibe sempre as mesmas informações
- Criado com `HTML`, `CSS`, eventualmente `JS`
- Atualizações requerem alteração manual dos arquivos

### 🔸 Site Dinâmico
- Conteúdo gerado sob demanda
- Interage com banco de dados e scripts no servidor
- Utiliza linguagens como `JavaScript`, `Node.js`, `PHP`, `Python`
- Responde a ações do usuário com conteúdo personalizado

---

## ⚖️ Comparação Direta

| Característica       | Site Estático                   | Site Dinâmico                              |
|----------------------|----------------------------------|---------------------------------------------|
| Conteúdo             | Fixo                            | Gerado em tempo real                        |
| Atualização          | Manual                          | Automatizada via banco e lógica             |
| Tecnologias comuns   | HTML, CSS, JS simples           | HTML, JS, Node.js, PHP, Banco de Dados      |
| Exemplo              | Blog pessoal, página institucional | Loja virtual, sistema de agendamento      |
| Hospedagem           | Simples, qualquer servidor       | Requer ambiente com processamento server-side |

---

## 🔧 Tecnologias Envolvidas

### 📄 Estáticos:
- **HTML5** — marcação
- **CSS3** — estilo
- **JavaScript** — interatividade básica
- Ferramentas: Live Server, GitHub Pages, Netlify

### ⚙️ Dinâmicos:
- **Node.js + Express**
- **Banco de dados (MySQL, MongoDB)**
- APIs REST
- Integração com formulários, autenticação, dashboards

---

## 💡 Exemplos Práticos

### Site Estático:
```plaintext
Página de currículo com HTML/CSS
• Estrutura semântica
• Estilização responsiva
• Sem interação com dados externos
```
### Site Dinâmico:
```plaintext
Sistema de cadastro de usuários
• Formulário HTML
• Validação com JavaScript
• Backend Node.js processa e salva dados em MySQL
```

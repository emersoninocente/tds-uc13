## 📌 O que é uma rota?

> Quando usamos APIs precisamos informar qual o "rota" de queremos acessar para que possamos acessar as classes ou funções necessárias.

```js
const rotas = {
  "/": "Curso Técnico em Desenvolvimento de Sistemas - UC 13",
  "/customers": "Acessa classes referentes aos clientes",
  "/products": "Acessa classes e funções referentes aos produtos"
};
```
